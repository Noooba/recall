## Built with

Recall’s original application source uses the MIT license. Direct runtime dependencies: Next.js, React, React DOM, Motion, Radix Dialog and Zod (MIT); Lucide React (ISC); Hugging Face Transformers.js (Apache-2.0). Versions and evidence appear in the downloadable lockfile-based license inventory.

Package metadata alone is not a legal review of every distributed file. Uninstalled optional platform packages and entries without notice files remain review items.

## Fonts and design

Geist font files are served from this site and licensed under SIL Open Font License 1.1. The original OFL notice is retained with the files. No external font requests are needed.

The interactive paper stack and graphs use original CSS, SVG and React code. No stock photos, videos, audio or third-party 3D model files are used. Kokonut’s MIT card-stack source was consulted as a design reference; its notice is retained with the reference material. No paid 21st template was installed.

## AI model

Optional inference downloads onnx-community/SmolLM2-135M-Instruct-ONNX-MHA from Hugging Face. Its card names HuggingFaceTB/SmolLM2-135M-Instruct as the base model. The conversion metadata does not expose a license field; converter-specific licensing and redistribution terms need review. Model weights are not included in the application submission archive. See the repository and base-model terms before commercial use or redistributing weights.
