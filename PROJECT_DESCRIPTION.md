# Recall AI

Your knowledge, ready when you need it.

Recall AI combines persistent local notes, source-linked keyword retrieval, offline study practice, and optional in-browser summaries and suggested titles. It extends the supplied Recall adaptive-learning app, preserving its deterministic knowledge-state engine.

The final, accurate submission description and copy-and-paste project text are in [HACKATHON_SUBMISSION](docs/HACKATHON_SUBMISSION.md). See [README](README.md) for setup, [FEATURES](docs/FEATURES.md) for current functionality, and [TESTING](docs/TESTING.md) for executed checks. Earlier unverified model-based concept extraction, generative answers, and AI grading are not presented as working features in this submission.
